# Posters

Key art for eight Apollo productions, lifted out of the behind-the-scenes
delivery it arrived in. Every title below was read off the poster itself —
each one carries its own title and credit block — so none of this is inferred
from filenames.

Two sizes ship for each: `-thumb.webp` at 640px and `-view.webp` at 1600px.
The masters are in `assets/backstage/_src/`, which is gitignored; the original
filename for each is in the table so a master can be found again.

21 posters, 8 films.

## Notes

- **La Casa De Raisa Vanessa vs Amore Serpente.** Three posters print both,
  the series name above and `Amore Serpente` beneath it; four print only the
  series name. They are filed by the smaller of the two, because that is the
  film each was cut for. The catalogue carries both as separate entries.
- **The catalogue has near-duplicate slugs** for some of these films
  (`raisavanessa` / `raisavanessa2`, `amoreserpente` / `amoreserpente2`,
  `drole-de-monsieur-ii-leone` / `…-dining`). The first of each pair is used
  here; adjust if the other is the canonical one.
- One frame in the same delivery was a phone screenshot of the site open in
  Instagram, not artwork. It is excluded by name in `tools/backstage-data.mjs`.
